# MoneyBuddy
O Money Buddy é uma aplicação web que ajuda jovens adultos a cuidar das próprias finanças: acompanhar receitas, categorizar despesas, entender obrigações fiscais e aprender conceitos de educação financeira, com foco em acessibilidade e privacidade dos dados. O mascote do app é o Buddy, uma capivara que faz referência ao mascote da UFABC.
